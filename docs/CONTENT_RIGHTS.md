# 콘텐츠 출처

영어 대본, 문제, 표현 설명은 이 앱을 위해 자체 작성했습니다. 외부 영상/자막/이미지는 포함하지 않았습니다. 오디오는 macOS Samantha 음성 합성으로 생성한 개발용 샘플입니다. 실제 서비스에 사용하기 전 음성 제공자의 배포 조건을 확인하고 적절히 라이선스된 음성 또는 직접 녹음한 음원으로 대체하세요.

`scripts/generate-audio.mjs`로 macOS에서 샘플 WAV를 다시 생성할 수 있습니다. 외부 API 호출은 필요 없습니다. 실제 YouTube 콘텐츠 수업은 영상 권리자와 자막 사용 범위를 확보한 뒤 별도 통합해야 합니다.
