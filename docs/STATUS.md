# 최신 변경 — 로컬 YouTube 학습

사용자 요청에 따라 온라인 배포는 하지 않습니다. YouTube IFrame 플레이어, 시·분·초 구간 지정, 반복/속도 조절, 공개 영어 자막 및 자동 CC 가져오기, 자막 기반 받아쓰기, 메모 저장을 추가했습니다. 상세 검증은 `YOUTUBE.md`를 참고하세요. 아래는 이전 샘플 버전의 기록이며 YouTube/자막 관련 미구현 목록은 이 변경으로 일부 대체되었습니다.

# 구현 상태와 검증

2026-09-23

## 확인 완료
- 타입 검사, 도메인 테스트(축약/빈 답변/추가 단어, 토론토 DST, 복습 달력)
- 로컬 D1 마이그레이션
- API 통합: 익명 401, 프로필 저장, Start 중복 방지, 단계 전 정답 미노출, 첫 시도 불변, 7단계 완료, 표현 저장, GET 재조회
- 초기 UI 미리보기와 로그인/온보딩 표시
- WebMCP open_learning_view: 유효 입력 화면 이동, 잘못된 입력 거부

## 명세 대비 남은 작업
- 권한 확인된 YouTube iframe 통합, VTT/SRT 업로드/검증, 관리자 게시 워크플로
- 최소 14일분 카탈로그, 최근 14일 동일 영상 제외, 버전 고정/권리 만료/지역 재검증
- 관리자용 AI 초안/학생 설명, 첫 미학습 진단 및 장기 추세
- 시간대별 자정 배정은 현재 Start 시 결정되고 백그라운드 09:00 보장 없음
- 배정은 샘플 순환 방식. 관심사 설정은 보존하지만 가중치 개인화 아직 미적용
- 반복 횟수, 말하기 횟수, 오답 원인 자기판단, 받아쓰기 토큰별 diff
- 완전한 requestId 멱등 처리: 첫 답변/시작은 보호되지만 단계 이동/교체의 재전송 정책 추가 필요
- 운영용 정규화 관계 모델, 관리자 권한 테스트, 다중 사용자/동시 탭 부하 테스트
- 표현 원문의 권리 만료 처리와 버전 스냅샷, 보존 기간/개인정보 안내 확정

## 시간 기록
전경 탭에서 오디오 재생 중이거나 최근 60초 내 상호작용이 있을 때 15초마다 체크포인트를 보내며 서버가 최대 15초로 제한합니다. 15초 미만의 마지막 구간은 누락될 수 있으며, 브라우저 신호에 의존하므로 대략적인 활성 학습 시간입니다. 타이머가 수업을 자동 완료시키지 않습니다.

## 게시 전제
샘플 개발 앱은 본인 전용으로 게시합니다. YouTube/Netflix 콘텐츠를 다운로드하거나 자막을 수집하지 않습니다. 이 버전을 공개 서비스 출시 완료로 간주하지 않습니다.

## 최종 실행 확인
- 최종 프로덕션 빌드, 타입 검사, 린트 모두 통과 (경고 없음)
- 모바일 너비 390px에서 문서 가로 넘침 없음, 데스크톱 1440px 레이아웃 확인
- 브라우저에서 로컬 로그인/온보딩 저장/세션 시작/워밍업→처음 듣기 확인
- Sites 등록은 생성됐지만 작업 도중 설치된 Sites 플러그인 디렉터리가 사라져 필수 site-workflow.mjs 실행 불가. 소스 푸시와 온라인 게시는 수행하지 않음. .openai/hosting.json의 기존 project_id를 재사용해 추후 이어서 게시할 것.
- 브라우저 재생 버튼 클릭 후 일시정지 상태 전환 확인. 실제 청취 품질은 사용자 확인 필요.
- /lesson 새로고침 후 처음 듣기 단계와 활성 시간 복원 확인.
- 음파 막대의 소수점 직렬화로 생긴 React hydration 경고를 정수 높이로 수정.
