# Netflix 연결 (로컬 Chrome, 2026-09-24)

## 0.2.1: 자막 줄바꿈과 목록 흔들림 수정

`textContent`가 `<br>` 등의 경계를 없애 두 줄을 `heryou`처럼 이어 붙이던 문제를 화면의 `innerText`를 읽어 해결했습니다. 확장 파일을 0.2.1로 교체하고 `chrome://extensions`에서 새로고침한 다음 Netflix와 앱 탭도 새로고침합니다. 기존 권한은 동일합니다. 앱은 0.2.0의 재생 제어도 허용하지만 자막 수집 수정은 0.2.1부터 적용됩니다.

기존 기록을 일괄 추측해서 변경하지 않습니다. 같은 구간을 다시 관측했을 때 새 줄바꿈만 제거한 텍스트가 기존 기록과 정확하게 일치하면 시각을 유지하며 새 줄바꿈을 반영합니다.

현재 문장 영역과 전체 목록은 일정한 높이를 유지하고, 행 상태 표시와 페이지 이동 공간을 항상 확보합니다. 스크롤바 공간도 고정하여 자막 추가나 재생 상태 변경에 따른 레이아웃 이동을 방지합니다. 로컬 합성 화면에서 99→101개 추가, 현재 문장과 메모 버튼의 표시 전환, 행의 재생 표시 변경 전후 목록 위치·높이·너비와 스크롤 위치가 동일한 것을 확인했습니다.

## 0.2.0: 구간 반복 M7375 대응

0.1.0은 HTML 영상의 `currentTime`을 직접 변경했습니다. 사용자가 반복 시작 직후 M7375를 보고하여 이 경로를 제거했습니다. 0.2.0은 Netflix 본편 세션의 `seek(milliseconds)`, `play()`, `pause()`만 사용합니다. 현재 시각과 영상 길이도 동일한 플레이어에서 읽어 초 단위로 변환합니다. Netflix API에 접근할 수 없으면 명령을 중단하며 HTML 영상으로 우회하지 않습니다.

확장 ZIP을 설치했다면 다시 내려받아 기존에 로드한 폴더의 파일을 교체하고 `chrome://extensions`에서 새로고침합니다. 프로젝트의 `extensions/netflix-companion`을 직접 로드했다면 확장 새로고침만 필요합니다. 버전이 **0.2.1**인지 확인하고 Netflix와 학습 앱 탭을 모두 새로고침하세요. 오류가 난 Netflix 탭은 다시 로드해야 복구됩니다.

`scripting` 권한으로 요청한 Netflix 탭의 MAIN 실행 환경에서 패키지에 포함된 재생 함수만 실행합니다. Netflix 내부 플레이어는 공개된 안정 API가 아니어서 변경될 수 있습니다. [Mozilla의 Netflix 재생 래퍼](https://github.com/mozilla/gecko-dev/blob/master/browser/extensions/pictureinpicture/video-wrappers/netflix.js)도 이 플레이어의 밀리초 기반 메서드를 사용합니다.

직접 DOM 위치 변경을 금지하는 모의 영상으로 구간 반복, 초/밀리초 변환, 미지원 API 중단, 회차 변경과 연결 종료를 검증했습니다. 실제 사용자 Netflix 세션의 M7375 해소 여부는 수정판 설치 후 확인이 필요합니다.

`http://127.0.0.1:5173/netflix`에서 설치 안내와 연결 기능을 사용합니다. Netflix는 공식 탭에서 로그인/재생합니다. 계정 비밀번호나 쿠키를 앱에 입력하거나 복사하지 않습니다. 브라우저가 Netflix 로그인 세션을 유지합니다.

## 처음 설치

1. `npm run dev -- --hostname 127.0.0.1`로 앱을 실행합니다. 포트는 5173이어야 합니다.
2. 일반 Chrome의 `chrome://extensions`에서 개발자 모드를 켜고 **압축해제된 확장 프로그램 로드**를 선택합니다.
3. 이 프로젝트의 `extensions/netflix-companion` 폴더를 선택합니다. 앱 화면에서 ZIP을 내려받아 압축을 푼 폴더를 선택해도 됩니다.
4. 앱과 Netflix 탭을 새로고침합니다. Netflix 공식 화면에서 로그인 후 본편을 재생합니다.
5. 앱의 **확장 프로그램 연결 확인**을 누르고 연결할 영상을 선택합니다.

확장 프로그램 업데이트 시 확장 관리 화면에서 새로고침 후 두 탭을 새로고침합니다. 소스 수정 후 ZIP 갱신은 `npm run netflix:package`입니다. 설치는 사용자가 Chrome에서 직접 수행합니다.

## 기능과 동작

- 공식 Netflix 탭의 자체 플레이어를 통한 재생/일시정지/시각 이동, 시·분·초 반복 구간.
- 반복을 끄면 영상은 구간 끝 이후에도 계속 재생됩니다.
- 구간/제목/메모는 기존 로컬 학습 저장소에 계정별로 저장합니다.
- 연결한 Netflix 화면에 표시되는 자막을 재생 시각과 함께 자동 기록합니다. 기록은 영화·회차의 watch ID별로 현재 브라우저의 IndexedDB에 즉시 저장됩니다. 같은 브라우저 프로필과 앱 주소에서 다시 연결하면 복원됩니다. 줄바꿈을 보존하려면 확장 0.2.1을 사용하세요.
- ‘자막 숨기기 / 보기’는 앱의 현재 문장과 선택 구간 자막 표시만 바꿉니다. 숨겨도 기록과 저장이 계속됩니다. 이미 기록한 구간은 Netflix 자막을 끈 상태로 다시 재생해도 앱에서 볼 수 있습니다.
- 실제로 화면에 표시된 부분만 수집합니다. 약 0.5초 간격으로 관측하므로 타이밍은 원본과 조금 다르고, 백그라운드 절전이나 연결 중단 중에는 누락될 수 있습니다. 반복해서 재생한 같은 시각의 같은 문장은 합치며, 다른 시각의 동일 문장은 별도로 보관합니다.
- 자동 자막은 이 기기의 브라우저 프로필에 저장되며 서버의 학습 계정별 메모와 별개입니다. localhost와 127.0.0.1도 별도 저장소입니다. 사이트 데이터 삭제 시 지워집니다. 작품당 최대 5,000개 / 150만 자의 기록을 보관하고 저장 실패 시 재시도 안내를 표시합니다. 시크릿 창의 저장소는 창 종료 시 삭제됩니다.
- VTT/SRT 파일을 별도로 등록해 재생 시각과 동기화할 수도 있습니다. 파일은 현재 탭에서만 유지되며 시간 조정이 가능합니다. 자동 기록은 파일을 보는 동안에도 계속됩니다.
- ‘전체 자막’에서 자동 기록 또는 등록한 파일의 모든 문장을 열람합니다. 100개씩 페이지를 넘길 수 있고 선택은 페이지 간 유지됩니다. 문장 왼쪽 체크박스로 다중 선택하거나 Shift로 연속 선택합니다. ‘구간 지정’은 A/B 입력값을 바꾸며, ‘선택 구간 반복’은 선택한 첫 문장부터 마지막 문장까지 즉시 반복 재생합니다. 사이에 선택하지 않은 문장도 포함됩니다. 파일 시간 조정값은 선택 구간에도 반영됩니다. 자막 숨김은 전체 목록도 숨기며 선택은 유지합니다.
- 현재 문장을 학습 메모에 넣고 구간과 함께 저장할 수 있습니다. 전체 자막 추출, 스트림 다운로드, DRM 처리에는 접근하지 않습니다.
- 연결 종료, 15초 동안 상태 요청 없음, Netflix 회차 변경 시 반복을 해제합니다. Chrome이 백그라운드 탭을 절전 처리하면 연결과 반복이 중단될 수 있습니다.
- 한 Netflix 탭은 한 학습 앱 탭에서만 제어합니다. 다른 회차의 오래된 명령은 거절합니다.
- localhost와 127.0.0.1의 **5173번 포트**에서만 로컬 연결 메시지를 받습니다. 외부 웹사이트에는 연결하지 않습니다.

## 검증 범위와 제한

연결 프로토콜과 영상 제어는 모의 영상/Chrome API 환경의 자동 테스트로 검증합니다. 실제 Netflix 계정의 로그인과 보호된 영상 재생은 사용자가 설치한 일반 Chrome에서 확인해야 합니다. Netflix의 화면 구조, 광고, 지원 브라우저 정책에 따라 시각 이동/자막 감지가 작동하지 않을 수 있습니다. 시각 이동 실패 시 반복을 해제하고 앱에 오류를 표시합니다. 재생 시작이 막히면 Netflix 탭에서 먼저 재생해 주세요.

공식 참고: [Netflix 지원 브라우저](https://help.netflix.com/en/node/30081), [Chrome 콘텐츠 스크립트](https://developer.chrome.com/docs/extensions/develop/concepts/content-scripts).

자동 자막의 병합·반복·구간 이동·CC 해제 시 기존 기록 보존은 단위 테스트로 검증했습니다. 로컬 브라우저의 합성 재생 화면에서 자동 저장, 숨긴 동안 추가 기록, 새로고침 복원, 회차별 분리, CC 없는 상태의 저장 자막 표시, 파일 등록과 메모 추가를 확인했습니다. 실제 Netflix 자막 감지 여부는 사용자의 Chrome 연결에서 확인이 필요합니다.
