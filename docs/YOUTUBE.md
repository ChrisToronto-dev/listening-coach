# YouTube 학습

## Vercel 배포

자막 버튼은 Next.js API `/api/youtube/captions`를 호출합니다. Vercel에서는 별도 Python 함수 `api/youtube-captions.py`가 yt-dlp로 공개 영어 자막만 가져옵니다. 프로젝트 루트의 `requirements.txt`로 Python 의존성을 설치하고 `vercel.json`으로 함수 제한 시간을 설정합니다. 로컬 `.venv`를 업로드할 필요는 없습니다. Next.js 프로젝트 설정과 `npm run build`는 유지하세요.

`APP_PASSWORD` 및 `APP_SECRET`은 같은 Vercel 프로젝트 환경 변수로 설정합니다. 자막 Python 함수도 기존 `lc_session` 로그인 쿠키를 검증합니다. Next.js API는 본인 영상인지 확인하고 기존 자막을 덮어쓰지 않으며, 가져오는 동안 학습 기록이 변경되면 충돌을 반환합니다.

YouTube가 서버 IP에 요청 제한이나 로그인 확인을 요구하는 경우 자동 가져오기는 실패할 수 있습니다. 오류 메시지에서 원인을 확인하고 자막 버튼 옆 **Upload VTT / SRT**로 파일을 올릴 수 있습니다. 2026-09-30 별도 Vercel 테스트 배포에서 지정 영상은 `LOGIN_REQUIRED`를 반환했습니다. 자동 다운로드 성공을 보장하지 않습니다.

운영 사이트의 고정 주소는 `https://listening-coach-seven.vercel.app`입니다. 배포마다 생성되는 주소는 해당 버전에 고정됩니다. 업데이트 후에는 고정 주소를 사용하세요. 원격 데이터베이스 환경 변수 없이 사용하는 `/tmp` SQLite는 임시 저장소이며, 배포·서버 교체를 넘어 기록을 유지하려면 Turso 등 공유 저장소를 설정해야 합니다.

## 사용

`npm run dev -- --hostname 127.0.0.1` 후 `/youtube`를 엽니다.

- 첫 화면의 지정 영상(All Ears English, `MxkVneD7-HY`) 또는 새 URL을 선택합니다.
- ‘영어 자막 가져오기’를 누르면 영어 자막을 우선 선택하고, 없으면 영어 자동 CC를 가져옵니다. 공식 IFrame API는 영상 재생에, 프로젝트 내 yt-dlp는 공개 자막에만 사용합니다.
- 영상/음성을 다운로드하지 않으며 브라우저 쿠키·프로필·로그인 정보도 사용하지 않습니다.
- 자동 자막은 오인식이 있을 수 있어 기준 문장임을 표시합니다. 일부 영상은 자막 없음, 로그인 필요, 지역/네트워크 제한으로 가져오기가 실패할 수 있습니다. 숨겨진 콘텐츠나 인증 제한을 우회하지 않습니다.
- 가져온 자막은 로컬 D1 학습 기록에 저장됩니다. 처음 듣기 전에 정답 문장을 API에 싣지 않으며 제출하거나 문장 확인을 눌렀을 때만 보여줍니다.
- 자동 CC의 중복 전환 구간을 제거하고 짧은 조각은 최대 14초까지 묶습니다. 구간 타임코드는 유지합니다.
- 구간 입력: Netflix 연습과 같은 A/B 구간 카드에서 시작·끝 각각 시/분/초를 입력하거나 ‘지금을 시작점으로 / 끝점으로’를 누릅니다. 재생, 처음부터 듣기, 현재 시각, 반복 켜짐/꺼짐이 한 영역에 표시됩니다. 반복을 끄면 영상은 구간 뒤에도 계속 재생됩니다.
- 전체 자막은 100개씩 페이지로 확인합니다. 체크박스로 여러 문장을 선택하거나 Shift로 연속 선택할 수 있습니다. ‘구간 지정’은 첫 문장부터 마지막 문장까지를 A/B 입력에 넣고, ‘선택 구간 반복’은 그 범위를 저장한 뒤 즉시 반복 재생합니다. 페이지를 이동해도 체크 선택은 유지됩니다.
- 자막 공개와 받아쓰기 학습 규칙은 그대로 유지합니다. 아직 확인하지 않은 문장은 목록에서 숨기고, 문장 확인 또는 첫 답변 뒤에 본문을 표시합니다. 숨겨진 문장도 타임코드 기준 구간 선택에는 사용할 수 있습니다.
- 받아쓰기 첫 제출은 잠기며, 문장을 미리 확인했으면 힌트 사용으로 기록합니다.
- 메모는 저장 버튼으로 보관합니다. 문장 선택 위치, 구간, 메모, 받아쓰기 결과는 새로고침 후 복원됩니다.

## 자막 도구 설치

Python 3.10+와 Node.js 필요. 현재 컴퓨터에는 설치 완료.

```sh
npm run captions:setup
npm run dev -- --hostname 127.0.0.1
```

`.venv/`와 `.local-captions/`는 Git에서 제외합니다. Next.js 개발 서버도 설치된 로컬 자막 도구를 사용합니다. Vite 개발 서버는 기존 로컬 전용 미들웨어를 사용합니다. Vercel의 프로덕션에서는 별도 Python 함수를 사용합니다.

Vite 로컬 자막 엔드포인트 `/api/youtube/captions`는 루프백 연결·호스트·동일 Origin·로컬 계정·영상 소유권을 확인합니다. 명령은 쉘을 거치지 않으며 유효한 11자리 영상 ID만 전달합니다. Vite에서는 동시 실행 1개·90초, Next.js 로컬에서는 45초 제한입니다.

## 검증

- `npm test`: URL 파싱, VTT/SRT 시간 검증, 자막 중복 정리, 시분초 변환, 답변 비공개/공개, 반복 경계, 기존 채점/복습.
- `PYTHONPATH=. .venv/bin/python tests/python-captions.test.py`: Python 함수의 로그인 만료·변조·Origin·영상 ID 검사. 외부 다운로드 없이 검증합니다.
- `node --experimental-strip-types tests/caption-function-smoke.mjs`: 실제 공개 YouTube 자막을 Python 함수로 가져와 정리합니다. 학습 기록은 쓰지 않습니다. 로컬 테스트에서 247개 영어 문장 구간 수집을 확인했습니다. Vercel의 서버 IP에서 성공하는지는 별도 확인이 필요합니다.
- `node tests/youtube-api.mjs`: 임시 데이터로 API 인증/소유권/중복/채점 잠금/메모/잘못된 구간/CSRF 확인 후 해당 임시 항목만 제거.
- 지정 영상의 공식 oEmbed 제목 확인, 영어 자막 179 cue 및 자동 CC 959 cue 수집 확인. 영어 자막은 정리 후 159개 학습 구간, 자동 CC는 191개 구간.

## 공식 자료와 도구

- https://developers.google.com/youtube/iframe_api_reference
- https://developers.google.com/youtube/v3/docs/captions/download (공식 다운로드에는 영상 편집 권한 필요)
- https://github.com/yt-dlp/yt-dlp (자막 옵션 및 설치)

공개 서비스용 권한 검수 카탈로그가 아니라 사용자가 요청한 로컬 개인 학습 경로입니다. 자동 가져오기 가능 여부가 콘텐츠 재배포 권한을 의미하지 않습니다.

브라우저 통합 확인: 앱의 ‘영어 자막 가져오기’ 버튼에서 159개 구간의 영구 저장과 받아쓰기 탭 전환을 확인했습니다. 실제 저장된 159개 자막 목록에서 체크박스 다중 선택, Shift 연속 선택, 선택 개수와 시간 범위 계산, 페이지 이동, 확인 전 문장 숨김을 확인했습니다. 영상 플레이어 연결이 20초 이상 지연되면 재시도/원본 보기 안내를 표시합니다.

미리보기 제약: Codex 내장 브라우저에서는 앱과 분리한 기본 HTML iframe도 빈 화면으로 남았습니다. 원본 YouTube 페이지는 열리므로 앱의 자막/DB 경로와 별개의 임베드 환경 문제로 추정합니다. 일반 Chrome에서 `http://127.0.0.1:5173/youtube`를 여는 안내를 추가했습니다. 이 환경에서는 실제 영상 재생·실시간 반복의 최종 확인은 완료하지 못했습니다. 반복 경계 로직의 자동 테스트는 통과했습니다.
